# Esoteric Language (Esolang) Learning Repository

このリポジトリは、様々な**難解プログラミング言語（Esolang）**を学び、実装したコードや学習メモを記録するための個人用リポジトリです。

## 📂 ディレクトリ構成

言語ごとにディレクトリを分けて管理しています。

```text
.
├── README.md               # このファイル
└── brainfuck/             # CowLang の学習データ
    └── hello_world.cow      
```

## 開発環境

将来的には自作コンパイラを開発して使用する予定ですが、現在はwebコンパイラやVSCodeの拡張機能等を使用して実行しています。
